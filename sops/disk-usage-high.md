# 磁盘使用率过高

## 处理步骤

1. 记录告警节点、异常挂载点、当前使用率以及大目录和大文件证据。
2. 确认大文件所属业务、日志轮转策略、保留要求和当前业务影响。
3. 在业务负责人确认且完成必要备份后，优先调整日志级别或恢复日志轮转，禁止直接删除仍在写入的文件。
4. 如需释放空间，必须按变更流程执行有边界的归档或清理，并在操作前后复查磁盘使用率和服务状态。
5. 若空间继续快速增长或业务异常，停止自动处置并升级给应用负责人和值班负责人。
